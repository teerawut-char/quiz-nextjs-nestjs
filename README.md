# Ticket Booking Platform (Dockerized)

โปรเจกต์ระบบจองตั๋วคอนเสิร์ตที่รันบน Docker แบบครบวงจร ทั้ง Frontend, Backend, และ Database

## วิธีการรันโปรเจกต์

ใช้คำสั่งเดียวเพื่อติดตั้งและเริ่มทำงานทุกอย่าง:

```bash
docker-compose up --build -d
```

*   `--build`: สั่งให้ Build Image ใหม่เสมอเพื่อให้มั่นใจว่าได้โค้ดล่าสุด
*   `-d`: สั่งให้รันแบบ Background (Detached mode)

---

## บริการที่มีในระบบ (Services)

เมื่อรันคำสั่งด้านบน ระบบจะเริ่มทำงานทั้งหมด 4 บริการ ดังนี้:

1.  **`api` (NestJS)**
    *   **Port:** `3001`
    *   **หน้าที่:** จัดการ Logic ทั้งหมด, เชื่อมต่อ Database, จัดการการจองตั๋ว
    *   **Startup:** เมื่อเริ่มรัน จะทำการล้างค่า Redis, อัปเดต Schema ฐานข้อมูล และลงข้อมูลเริ่มต้น (Seed) อัตโนมัติ

2.  **`frontend` (Next.js)**
    *   **Port:** `3000`
    *   **หน้าที่:** หน้าจอสำหรับผู้ใช้งานและ Admin (Dashboard)
    *   **Access:** เข้าใช้งานได้ผ่าน [http://localhost:3000](http://localhost:3000)

3.  **`postgres` (Database)**
    *   **Port:** `5432`
    *   **หน้าที่:** เก็บข้อมูลผู้ใช้, คอนเสิร์ต, และรายการจองทั้งหมด
    *   **Volume:** ข้อมูลจะถูกเก็บไว้ใน Docker Volume ไม่หายไปแม้จะปิด Container

4.  **`redis` (Cache & Locking)**
    *   **Port:** `6379`
    *   **หน้าที่:** จัดการระบบ Seat Locking เพื่อป้องกันการจองที่นั่งซ้ำซ้อนในเวลาเดียวกัน

---

## หมายเหตุเพิ่มเติม
*   ระบบจะทำการ **Flush Redis** (ล้างค่าทั้งหมด) ทุกครั้งที่รันแอปใหม่เพื่อให้สถานะการจองที่ค้างอยู่ถูกรีเซ็ต
*   ระบบจะทำการ **Seed Data** อัตโนมัติ (เช่น สร้าง Admin และข้อมูลคอนเสิร์ตเริ่มต้น)
